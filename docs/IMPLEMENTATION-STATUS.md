# Implementation status and evidence

Updated September 18, 2026. Objective remains **implement the full PRD end to end**, including the planned later capabilities. This is an implementation checkpoint, not a completion declaration.

## Current code

- [Automatic selection and download](AUTOMATIC-SELECTION.md) now supports explicit `download_when_ready` consent in addition to preparation-only requests. Selection, trusted automatic attempt, claims and download enqueue commit together. Current route approval, requester/approver authority, original profile and catalog identity are checked before submission. Approval changes do not prevent observation of existing transfers or silently authorize importing under a replacement policy. Whole-torrent size limits include padding. Real EPUB/audio worker workflows verify hardlinks, delayed ABS confirmation, member fulfillment and replay with synthetic external services. Standing list policies and scheduled searches remain pending.

- [Transfer and storage limits](CAPACITY.md) now provide administrator settings, endpoint slots, a rolling internal automatic-transfer budget and shared filesystem reservations. Admission uses actual filesystem identity and transactional storage generations; inspected torrent bytes, future copies and per-child imports share accounting. Verified staging survives low-space waits/restarts without reserving a second copy. Existing download/import schedulers resume waits, while uncertain submissions keep capacity. Standing list policy activation remains pending.

- [Reviewed list requests](LIST-REQUESTS.md) now select up to 100 titles, preview requested-media availability and compatible pending requests, and save ordinary wanted requests through an atomic durable worker. Independent reasons, cancellation before commit, expiry/retry, history, access redaction and mobile UI are implemented. This completes a manual batch-request subset; automatic list acquisition and inherited policies remain pending.

- Goodreads RSS subscriptions now observe shelf additions through durable scheduled workers, conditional requests and shared cooldowns. Private provisional titles, corroborated ISBN/catalog reuse, independent local/source membership, durable exclusions, manual matching, pause/detach and owner-only settings are implemented. Feed omissions preserve earlier books and matched books use existing library availability. See [Goodreads subscriptions](GOODREADS-SUBSCRIPTIONS.md). Reviewed CSV snapshots now support mapped columns, shelf/subset selection, private bindings and durable receipts; see [CSV list import](CSV-LIST-IMPORT.md). [Hardcover subscriptions](HARDCOVER-LISTS.md) now add account-backed own/followed/public list selection, fresh two-pass membership verification, source-only removals, durable exclusions and private catalog reuse. Policy activation/backfill and list-driven downloads remain pending.

- Book-level Sources now combines durable MAM and Prowlarr results with independent source status, reload persistence, private saved download profiles and explainable format/source/seed ranking. Wanted requests carry through the shared torrent/selection path; frozen profile format and transfer-size limits apply at selection and import. See [Book source search](BOOK-SOURCES.md). Complete automatic eligibility, series coverage, ABB and list policy inheritance remain pending.

- Prowlarr now has encrypted administrator settings, sanitized per-indexer capabilities, private expiring results, incremental source browsing and torrent-file resolution into the shared acquisition path. Native-MAM overlap, source generation/permission checks, cooldowns and source-specific locking are enforced. See [Prowlarr integration](PROWLARR-INTEGRATION.md).
